Application settings

Settings

YouTube

YouTube Data API

Stored only in this browser via localStorage. Enable YouTube Data API v3 in Google Cloud, then create an API key.

Local transcription

Whisper on this computer

CC checks this local service directly from the browser. It is used only when a YouTube video has no usable caption track.

VK

VK video comments

A user token is required by VK API method video.getComments. Keep it private: enter it here, not in GitHub or source code.

Instagram

CC Browser Helper

Install helper/chrome/ as an unpacked Chrome extension. It opens Instagram in your existing signed-in browser session and returns comments that the page can display.

Server storage

PHP backend

Upload the contents of server/php/ to /cc/ on backend83.nadube.ru.

The token is stored locally in this browser and is sent only to your backend over HTTPS.

The connection check verifies PHP + SQLite first, then verifies access to the storage API when a token is present. Server synchronization itself will be enabled separately.
