Application settings

Settings

YouTube

YouTube Data API

Stored only in this browser via localStorage. Enable YouTube Data API v3 in Google Cloud, then create an API key.

Local transcription

Whisper on this computer

CC checks this local service directly from the browser. Recognition runs as a background job, so the transcript window can be minimized while you work with other sources.

VK

VK video comments

VK authorization is stored only on your PHP backend. CC automatically refreshes the one-hour access token using the server-side refresh token; no VK token is stored in the browser.

Instagram

CC Browser Helper

Install helper/chrome/ as an unpacked Chrome extension. It opens Instagram in your existing signed-in browser session and returns comments that the page can display.

Server storage

PHP backend

Upload the contents of server/php/ to /cc/ on backend83.nadube.ru.

The token is stored locally in this browser and is sent only to your backend over HTTPS.

The connection check verifies PHP + SQLite first, then verifies access to the storage API when an API token is present. Server synchronization itself will be enabled separately.
